# DockNova AI/ML Foundation

Machine Learning, Congestion Prediction, Operational Optimisation, and What-If Simulation engines for DockNova.

## Architecture

- `models/`: Trained model binaries, serialized artifacts, and model weights.
- `prediction/`: 72-hour congestion forecasting modules & feature inference.
- `optimisation/`: AI-based berth allocation and crane assignment solvers.
- `simulation/`: Scenario simulation engine ("What-If" operational disruption analyzer).
- `data/`: Dataset preprocessing, feature engineering, and pipeline definitions.
- `notebooks/`: Exploratory Jupyter notebooks for model research & prototyping.

## Purpose & Ownership

Maintained by AI/ML developers. Enables independent development, experiment tracking, and model tuning.
