# DockNova Shared Layer

Single source of truth contract layer shared across Frontend, Backend, Database, and AI services.

## Architecture

- `types/`: Shared TypeScript and domain type definitions.
- `schemas/`: Shared data schemas and validation contracts.
- `constants/`: System-wide constants, operational risk thresholds, and default values.

## Purpose & Ownership

Team-wide shared contracts. Any modifications here must be deliberate and reviewed across frontend, backend, and AI/ML teams.
