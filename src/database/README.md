# DockNova Database Foundation

Database structure management, schemas, seed data, and migration scripts for DockNova.

## Architecture

- `migrations/`: Version-controlled schema migration scripts.
- `schemas/`: DDL definitions, table schemas, and indexing models.
- `seeds/`: Seed scripts and sample data files for development/testing.
- `scripts/`: DB administration, setup, and backup automation scripts.
- `config/`: Database connection parameters and pooling configurations.

## Purpose & Ownership

Maintained by Database developers. Allows managing data models, indices, and seed data independently from backend code.
